## Números (ads-math)
- Margen por pedido: kit ~27 €, suelto ~26 € (sin IVA). Mezcla 60/40 → ~26,6 €.
- Contra reembolso: si se rechaza ~20 % (supuesto a medir), el margen efectivo baja a **~19–20 €** → **CPA de equilibrio ≈ 20 €**.
- Coste por visita real (cojín: 62 € → ~235 visitas = 0,27 €; en BF supón 0,35–0,60 €).
- Conversión necesaria para no perder: 1,5 % (a 0,30 €/visita) · **2,3 % (a 0,45 €)** · 3 % (a 0,60 €).
- Con 150 €: ~330 visitas → 1 % = 3 ventas (−90 €) · 2 % = 6–7 ventas (≈ 0 €) · 3 % = 10 ventas (+45 €).
- Es una prueba de validación, no una apuesta segura.
